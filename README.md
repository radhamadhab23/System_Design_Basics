# 🧠 System Design Basics

Welcome to the **System Design Basics** repository!  
This repo is a growing collection of **hands-on code examples**, **patterns**, and **practical demonstrations** of common system design components used in modern scalable applications.

---

## 📚 Contents

| Module                   | Description                                                                 |
|--------------------------|-----------------------------------------------------------------------------|
| [`messagequeue/`](./messagequeue)       | Concepts of asynchronous communication using RabbitMQ queues in Node.js.          |
| &nbsp;&nbsp;&nbsp;&nbsp;└── `message_queue_demo/` | Simple demo of Producer → Queue → Consumer with Docker + RabbitMQ.               |
| *(Coming soon)*          | Redis Caching, Load Balancer Setup, API Gateway, Pub/Sub, etc.             |

---

## 🎯 Goal

This repo aims to **bridge theory and practice** in system design by providing:

- 🚀 Realistic code examples  
- 🧱 Modular folder structure for each component  
- 📦 Docker-based reproducibility  
- 📘 Explanations for each use case  

Perfect for students, backend developers, and engineers preparing for system design interviews or building backend systems.

---

## 🛠 Prerequisites

To run most examples:

- [Node.js](https://nodejs.org/)
- [Docker](https://www.docker.com/)
- [RabbitMQ (via Docker)](https://hub.docker.com/_/rabbitmq)
